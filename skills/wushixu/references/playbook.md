# 场景剧本与产出模板

> 4 个场景的提问骨架 + 重点透镜 + 产出侧重。先认场景（可混合），取对应骨架。透镜定义见 `framework.md`。

## 通用产出骨架

1. **三道目光**：物 / 势 / 序（各 2–4 条，允许「淡」读数）
2. **核心判断**（按场景，见下）
3. **行动建议**：补物 / 借势 / 造序（择要，不必三样都给）
4. **边界声明**：哪些没把握、§19 哪条在起作用
5. 文风：短句、命题式、留白、避免 AI 腔

---

## 场景一：困局诊断（为什么卡住 / 失速 / 衰败）

**该问的（交互补料）**：现状是什么？卡在哪个环节？已经试过什么、效果如何？这事持续多久了（定位快慢钟）？

**重点透镜**：三失配定位断点（物→势 / 势→序 / 序→物 哪条断了）；找慢变量（底下漂移的是什么）；找被甩开的刹车 / 该破的硬河床。

**核心判断**：断在哪条边 + 根因（物、势，还是序的问题）+ 最小撬动点（弱者之用：在哪使劲最省）。

**最常见误诊**：把序失配当成物失配——拼命补资源，其实是结构锁死。

**反模式参照（§17.7）**：账面三强却空转 → 查「序→物」自不自维持（WeWork 假飞轮）；把弱规则误判成无序 → 看它接不接得住势（维基百科）。

---

## 场景二：决策与介入（该不该做 / 从哪下手）

**该问的**：有哪些选项？硬约束是什么（钱 / 时间 / 不可逆性）？目标与底线？这步可逆还是不可逆？

**重点透镜**：决策六步（§18）；辨阴阳（这步的代价 / 反面）；用弱切入（能否小成本试、保留选择权）；造序视角（成了之后如何固化进序）。

**核心判断**：该不该做 + 从哪下手（最小试错路径）+ 若成如何固化。**涉及「何时」的判断，明标这是框架弱区（§19.2）。**

---

## 场景三：趋势研判（会怎么演化 / 真势还是虚热）—— 对齐 case/07

**该问的**：标的是什么？时间窗多长？已知硬事实有哪些？

**必做调研**：派 subagent 拉事实锚（多源交叉、标注口径存疑、不臆造）。**事实不足，不下判断。**

**重点透镜**：三道目光（务必区分「对象本身的物势序」与「价格/表象的物势序」——张力常在这条快慢钟的缝上）；**真势 vs 虚热（先过势三硬条件：源于差？有方向？能改物或序？§3.2）**；飞轮有没有连着刹车；快慢失配；慢变量临界 + 快变量轻触。**反模式（§17.7）**：有势无序＝Clubhouse（势是快钟，没结成序就连本带利还回去）。

**产出模板（仿 07）**：

1. **先声明边界**（§19.2：判性质强、判时间弱）
2. **三道目光**：物 / 势 / 序
3. **核心判断**：真势还是虚热？**判据链**（每条落在正文概念上）
4. **可证伪预测**：3–4 条命题，**各带主观概率 + 检验方式**
5. **★ 证伪条件**：事先写死「框架被打脸的样子」
6. **事实锚**：来源、抓取时间、硬数据 vs 存疑逐条标注；声明全程未臆造
7. **诚实标注弱区**：哪里可能低估 / 高估

> 若是 LIVE 事前预测，建议立时间戳锁档 + 设回看时点，落 `13-物势序论/case/`（破后验/确认偏误）。

## 场景四：现象解释与复盘

**该问的**：要解释 / 复盘的对象与问题是什么？你想得到「解释」，还是想提炼「可复用的经验」？

**重点透镜**：三道目光（结构性解释）；循环（物势序怎么转成这个结果，哪条边主导）；进化（留下来的是什么可遗传的序）。

**核心判断**：

- **解释** → 用物势序结构说清「为何如此」，点出主导的那条边 / 那个断点。
- **复盘** → 三道目光回看 + 提炼**可遗传的序**（能在新物上重新落形的组织模式），区分一次性运气与可复制的序；存活 ≠ 正当（§13.5）。**可复制 ≠ 该复制**——过了耐久前两关、栽在正当性第三关的标本＝传销（§17.7）。

## 跨场景：何时停、何时说「框架使不上力」

- 纯事实查询 / 纯价值判断 / 窄技术最优化 → 直说不适用，指向该用什么。
- 信息严重不足且无法调研 → 说清缺什么，不硬分析。
- 某道投影全淡 → 如实报「此处无 X」，这本身是诊断，不是失败。
