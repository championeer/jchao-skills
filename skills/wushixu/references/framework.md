# 物势序框架速查

> 从 `wushixu_theory.md` 蒸馏的**方法层**，供分析时取用。正文是唯一真相；正文改了，这里跟随。
> 意象一律「照明，不作证明」（§4、§11.7）——用来照亮判断，不用来代替判断。

## 三元（§3、§5）

- **物 = 承载**：真实存在什么？人、钱、时间、产品、技术、身体、资产、渠道、组织规模、供应链、制度约束。看物要追问：这些在**当前环境**还算不算资产（资产↔负担会翻转）。
- **势 = 驱动**：力量正往哪流？需求、政策、资本、用户偏好、士气、欲望、恐惧、现金流压力、技术周期、竞争、时代红利。看势看**方向、速度、持续性、反噬点**。**势有三个硬条件（§3.2）：① 源于差**（落差才生势，绝对均匀无势）**、② 有方向**（指向性驱动，来回振荡的噪声不算）**、③ 能改物或序**（真能重配资源、撬动结构）。三条缺一即虚热——热度/情绪/信息本身都不是势，**能改资源配置、改行为关系、引发行动迁移的，才是**。
- **序 = 组织**：靠什么规则把自己组织起来？商业模式、组织结构、流程、制度、算法、平台规则、文化、信任、激励、分配、反馈回路。**序是最高变量**——信息只有进入序，才变成现实力量。

## 三道目光 / 观察三问（§4、§14.1）

同一对象，三问都有答案、互不替代、互相牵动：

- **此中有何物？**（位形：它此刻承载什么）
- **此物有何势？**（倾向：它被推往哪）
- **此势成何序？**（法则：它靠什么自组织）

某道投影很淡 = 有用读数（如「一池死水，无势可借」），不是失败。**看不见，本身就是一种看见。**

## 判断三配（§14.2）

系统是否健康，看三配：**物足？**（够不够/是否过重/是否错配）**势同？**（内部努力与外部趋势是否一致）**序通？**（结构/规则/反馈能否承载资源与趋势）。

## 三失配 = 循环三断点（§7、§11.5）

| 失配 | 断在哪条边 | 形态 | 行动 |
|---|---|---|---|
| **物失配** | 物→势 断 | 死水 / 积在错地方 / 落差指向错向 | 补物、减物、换物、重配物 |
| **势失配** | 势→序 断 | 有流量无转化 / 逆势对撞（越使劲越偏） | 识势、顺势、借势、避势、蓄势 |
| **序失配** | 序→物 断 | 旧河床锁死物（Kodak、晚秦） | 调序、破序、重序、造序 |

## 行动三法 / 战略三层级（§14.3、§15）

- **补物（低）**：缺什么补什么。必要，但单纯堆资源解决不了结构问题。
- **借势（中）**：让外部动力替你做工。顺市场 / 技术 / 政策 / 心智之势。
- **造序（高）**：重组关系、规则、分配、反馈，让资源与力量围绕新结构运行。**最高行动**——动的是循环的约束层（河床一改，水与沙全重排）。

## 动态透镜（按需取用，勿全套堆砌）

- **循环（§11）**：物→势→序→物。物的不平衡点火出势，势反复流动沉淀成序，序回头铸物。三处失配即三处断点。
- **真势 vs 虚热（§3.2）**：研判时的头道闸——用势的三硬条件筛：源于差？有方向？能改物或序？三条全过才是真势，缺一即虚热。先验真，再谈方向与速度。
- **飞轮 / 刹车（§11.3）**：圈朝增强转=飞轮（马太/复利/泡沫），朝平衡转=刹车。**看一个高歌猛进的系统危不危险，就看它有没有一只还连着的刹车。**
- **硬序 / 活序（§11.4）**：硬河床（制度/流程，定形快、改要爆破、过刚则脆）；活河床（文化/信任，柔韧自愈、养成慢、可淤塞）。健康=硬定形+活养护。
- **三种时钟（§12）**：势快（天/周）、物中（年）、序慢（代）。**失配的真相 = 快钟已换向、慢钟还卡在原处。**「看见」和「改得动」分属两只不同速度的钟。
- **慢变量（§12.4）**：平时几乎不出声，越过临界骤然崩塌。真正的预警去听**最安静的慢钟**，不是最吵的快钟。
- **阴阳（§8）**：资产↔负担、红利↔泡沫、效率↔韧性、稳定↔僵死、控制↔创新。看一种力量是否走向极端、是否在积累反向力量。
- **反者道之动（§9）**：凡盛处看衰因、强处看弱点、主流处看边缘、秩序处看裂缝、增长处看代价。
- **弱者道之用（§10）**：未明以弱探路、势起以弱借力、旧序以弱穿透、成事以强固化。**快钟上用弱（试错快而轻），慢钟上成强（固化进序）。** 弱 = 对「在哪使劲」的精算——找循环最薄弱的接口去撬。
- **进化筛选（§13）**：造序=变异、环境=选择、可复制的序=遗传。目的只在变异端，选择端永远无目的。**能吸收势的序 > 靠刚性压制势的序**（更耐筛）。**最高的造序＝三重判据（§13.6）：① 有效性**（接得住势）**、② 适应性**（扛得住变、可复制）**、③ 正当性**（值不值得传）。**前两重理论替你判**（耐久的两面），**第三重理论判不了、却不许你跳过**——存活 ≠ 正当（耐久之善，不是道德之善）；把正当性留给你不是放手，是定责。

## 四个反例：框架边角的判别力（§17.7）

正文拿四个「第一眼像反例」的事撞框架，撞出四处判别力——分析时当反模式照：

- **WeWork（账面三强却崩）→ 循环 > 三要素**：物势序盘点齐全 ≠ 接成自转的圈。专查「序→物」那条边**自不自维持**——靠外部输血（融资）拨动的是假飞轮（风车），断血即停。账面体检照不出假飞轮。
- **Clubhouse（物薄序虚却冲顶）→ 势能独立点火，但留不住**：一股猛势足以把物序皆薄的东西顶上天，可**势是快钟**，不结成序（留存/网络/变现）就连本带利还回去。「短期成功」常是这种有势无序。
- **维基百科（无主编却赢权威）→ 别把弱规则读成无序**：序的强弱不看规则硬不硬、中心实不实，看**接不接得住势**。活河床（协议/共识/自愈）可胜过硬河床（权威/编审）。**最弱的规则，可能是最强的序。**
- **传销（最能复制却最不该）→ 可复制 ≠ 该复制**：自维持＋可复制只过了理论能判的前两关（耐久）；第三关正当性，理论不替你判。前两关满分、第三关零分的标本。

## 决策六步（§18）

1. **看外部环境**：外部物/势/序；什么在变轻变重、增强衰退、开裂形成。
2. **看内部主体**：我的物/势/序；资源是资产还是负担、动力是真势还是虚热、结构能否承载新机会。
3. **找失配点**：物不足还是太重？逆势还是没借到势？序能否处理信息？短期问题还是系统问题？
4. **辨阴阳**：优势的反面、增长的代价、强处的脆弱、秩序的裂缝、边缘的新力量。
5. **用弱切入**：小规模试错？低成本验证？借外部趋势？从边缘进入？保留选择权？
6. **形成新序**：有效做法如何产品化 / 流程化 / 制度化 / 生态化 / 文化化。

## 边界（§19，硬护栏）

1. **不替代具体知识**——行业、技术、财务、法律、人性、政策、周期仍需具体研究。
2. **不精确预测时间**——趋势何时爆发、旧序何时崩，有滞后与偶然。
3. **不自动判断善恶**——高效未必正当，强大未必值得维护。

**框架是思考起点，不是思考终点。**

## 口诀（§20）

看事先看物势序，看变再辨阴阳反，做事贵在以弱用，成事终归造新序。
