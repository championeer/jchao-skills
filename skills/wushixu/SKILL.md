# wushixu — 物势序分析

用《物势序论》当透镜，把一个现实处境拆成 **物（承载）、势（驱动）、序（组织）** 三道目光，给出判断与行动建议。

**理论唯一真相**：`13-物势序论/wushixu_theory.md`（0–21 节）。本 skill 是它的**应用层**，方法从正文蒸馏（见 `references/framework.md`）。正文变了，framework.md 跟随——**勿各自漂移**。

## 边界（先判，再做）

这套透镜对「系统 / 动态 / 困局 / 演化」类问题锋利，对下列问题钝——**遇到就老实说框架使不上力、指向该用什么，然后停**：

- 纯事实查询 → 搜索 / deep-research
- 纯价值 / 伦理判断 → 理论 §19 明言不判善恶
- 窄技术最优化、需专业领域知识的执行 → 对应专业

正文 §19 三条边界是硬护栏：**不替代具体知识、不精确预测时间、不判善恶。**

## 流程

1. **判适用性** —— 不适用就按上面停。
2. **认场景** —— 困局诊断 / 决策与介入 / 趋势研判 / 现象解释·复盘（可混合）。读 `references/playbook.md` 取对应骨架。
3. **交互补料** —— 用 AskUserQuestion 问关键缺口（playbook 每个场景列了该问什么）。信息不足别硬分析。
4. **按需调研** —— 需要事实 / 数据 / 案例时（尤其研判），派 subagent（`Explore` 或 `deep-research`）补料；要求多源交叉、标注存疑、**全程不臆造**。
5. **三道目光** —— 扫物 / 势 / 序（见 framework.md）。某道投影很淡是**有用的诊断**（此处无势可借），不是失败。
6. **动态透镜** —— 按场景**取用、不全套**：快慢失配、飞轮/刹车、真势vs虚热、阴阳/反/弱、断点定位、慢变量临界。
7. **判断 + 行动** —— 判断三配（物足？势同？序通？）+ 行动三法（补物/借势/造序）；决策场景走六步模板。
8. **产出** —— 见下。
9. **沉淀案例** —— 分析完落一份 case 存档供复盘（见「案例沉淀」），**每次必做**。

## 三处护栏（不可破）

- **反普氏之床** —— 不把问题硬塞进框架、不堆「河床/飞轮/筛子」黑话。意象是**照明，不作证明**。判断要从问题本身长出来、再用框架语言表达，**不是反过来**。宁可说「此处无势可借」，不硬凑。
- **守边界** —— 见上。不适用就说不适用。
- **信息纪律** —— 研判 / 需事实类，必须 事实锚 + 多源 + 标注存疑 + 不臆造。输入是假的，整篇分析就是空中楼阁。

## 产出契约

一份物势序分析（随场景调整，模板见 `references/playbook.md`）：

- **三道目光**：物 / 势 / 序（含「淡」读数）
- **核心判断**（按场景：断点 / 下手点 / 真势vs虚热 / 结构）
- **行动建议**（补物 / 借势 / 造序，或决策六步；择要，不必三样都给）
- **边界声明**（哪些没把握、§19 哪条在起作用）
- **研判场景额外**：可证伪预测（带主观概率）+ 证伪条件 + 事实锚，对齐 `13-物势序论/case/07-智谱港股-LIVE/README.md`

文风遵正文 §3：短句、命题式、留白、克制，避免 AI 腔。

## 案例沉淀（每次调用必做）

每次 wushixu 分析完，落一份 case 到 `13-物势序论/case/`，供日后复盘——既复盘决策、又检验框架准不准（同 07 案例的双重价值）。规则与模板见 `references/case-logging.md`。要点：

- 编号续 08+，目录 `case/NN-<短名>/README.md`，并在 `case/README.md` 登记。
- 记：时间戳、场景类型、问题、三道目光、核心判断、建议；**研判类**带可证伪预测 + 回看时点，**其它类**带软回看条件。
- 回看记录留空，到点再填。涉隐私的私人事务正文脱敏——存档为复盘、不为公开。
